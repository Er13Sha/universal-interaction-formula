# h2-3d: модель W = Q·N — реализация, проверки, границы

29.10.2026. Файл: `h2-3d.html`.

## 1. Формула

`W = Q·N` (Катющик):

- `Q` — поле, создаваемое телами;
- `N` — количество материи (по умолчанию масса);
- сила на тело `F = N·Q`, ускорение `a = (N/m)·Q`;
- при `N = m` ускорение равно `Q` — принцип эквивалентности.

Поле считается по всем телам:

`Q(x) = Σ_j kQ·N_j·(r_j − x)/|r_j − x|³ · (1 − occ)`,

где `occ` — затенение промежуточным телом `k`: если его угловой радиус `Rs_k/r` перекрывает направление на источник, вклад ослабляется.

## 2. Атомные единицы

- `m_p = 1836`, `m_e = 1`;
- `K = 1`, `r0 = 1` (бор);
- `G = 2.4·10⁻⁴³` — реальная гравитационная постоянная в атомных единицах;
- `kField = 250` — кор (упругое перекрытие полей `Rf = 1`);
- `dampP = 0.02`, `dampE = 0.002`.

Отношение `F_G/F_C = G·m_p²/K = 8.09·10⁻³⁷` — как в реальности.

Ползунок `log10 G` от `−45` до `6`; при изменении `G` шаг адаптируется:
`dt = (1/120)/√(max(1, G))`, до 400 подшагов за кадр.

## 3. Проверки

### 1/r²

Два протона, `K = 0`, `G = 1`:

| R | Q | Q·R² |
|---|---|---|
| 1 | 1.836·10³ | 1.836·10³ |
| 2 | 4.590·10² | 1.836·10³ |
| 4 | 1.148·10² | 1.836·10³ |
| 8 | 2.869·10¹ | 1.836·10³ |

`Q·R² = G·m_p` — точно.

### Тень (дифференциальный тест)

Источник `x=−3`, экран `x=−2`, цель `x=+3`; вклад источника получен вычитанием прямого притяжения экрана:

| смещение экрана | доля вклада источника |
|---|---|
| 0 | 0.000 (полностью закрыт) |
| 0.05 | 0.500 (частично) |
| 0.3 | 1.000 (не закрыт) |

### Орбита

Один атом, 6000 шагов `dt = 1/240`, без демпфирования:

- `dE/E = 3.8·10⁻¹²`,
- `dL/L = 1.7·10⁻¹⁵`.

С демпфером `dampE = 0.002` энергия и момент убывают — это штатная диссипация, а не ошибка интегратора.

## 4. Регрессия (фактический файл)

| Тест | Результат |
|---|---|
| Один атом | `r = 0.974…1.000` — устойчиво |
| `H⁻` | `r = 0.150…3.426`, улёта нет за 5 с — метастабильно |
| `H₂` | `R: 1.51 → 2.48`, `E_связи = +26` — не связано |
| Кнопка «молекула» | ставит пару на `R = 2.00` (граница кора) |

## 5. Границы модели

- При честном `G` БГП невидим: молекулярной ямы нет, `H₂` не связывается — это физически правильно.
- При усиленном `G` (ползунок) появляется мелкая яма `~1–2` у `R ≈ 2Rf`; это демонстрация, не химия.
- `H⁻` метастабилен: классическая система без спина/Паули/корреляции не даёт устойчивого связанного состояния.
- Кор `kField` необходим: без него БГП/кулон сминают пару в точку.
- Настоящие молекулы и `H⁻` требуют квантового слоя (орбитали, Паули, корреляция).

## 6. Известные ограничения

- Затенение приближённое (конус, без точного перекрытия).
- `vOrb` при больших `G` растёт как `√(G·m_p)` — новые атомы запускаются быстро.
- Молекула ставится в точку нулевой силы, а не в минимум `U(R)`; при честном `G` это просто граница кора.
