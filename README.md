# h2-3d: чистая модель W = Q·N — реализация и проверки

31.10.2026. Файл: `h2-3d.html`.

## 1. Формула

`W = Q·N_w` (Катющик; монография, стр. 32–34; «Формула мироздания», 14:27):

- `W` — воздействие;
- `Q` — качественный показатель воздействия: `Q = k_a·C1/(4πR²)`, где `k_a = 1`, `C1` — интенсивность базового воздействия, `R` — расстояние до источника;
- `N_w` — количественный показатель (заряд): `N_w = V·q = h·S·q`; для сферы `S = πr²`, `h = 4r/3`, `V = hS = (4/3)πr³`; для тяготения заряд — масса;
- `F = f(α)·n_f·W`, `n_f = k_v·hSq = m`; для тяготения `k_v = 1`, `f(α) = 1`, откуда `F = C1·m1·m2/(4πR²) = G·m1·m2/R²`.

В коде всё взаимодействие идёт через одну функцию `QN(r, R, N_j) = Q(r)·N_j`, где `Q(r) = k_a·C1/(4πr²)` и `C1 = 4πG`:

- `W_i = Σ_j Q_j·N_j` — вектор на источник;
- `F_i = f(α)·n_f·W_i`, `n_f = k_v·N_i`;
- `a_i = F_i/m_i`, где `m_i = k_v·N_i`.

Константы `k_a`, `k_v`, `f(α)` в коде явные (`K_A`, `K_V`, `F_ALPHA`) и равны 1.

Внутри шара источника действует только та часть заряда, что попала внутрь: `N(r) = V(r)·q = N·(r/R)³` — это та же `N = Vq`, а не обрезка `r`. Для пары берётся `R = max(rad_i, rad_j)`, поэтому действие равно противодействию.

Из той же формулы получаются:

- **энергия:** `U = −kQ·N_i·N_j·φ(r)`, где `φ = 1/r` снаружи и `(3R² − r²)/(2R³)` внутри; `−dU/dr` совпадает с силой;
- **начальные скорости:** круговая орбита из `a = Q(r)·(N_b·N_g/m_b + N_g·N_b/m_g) = v²/r`, импульс делится между телом и центром;
- **шаг интегрирования:** `dt = min(1/120, 0.02·√(r³/(kQ·(N_i+N_j))))` по самой тесной паре;
- **свечение поля (G):** `Q_j·N_j`, отнесённое к полю протона на `r0`.

В модели нет кулона, кора `kField`, БГП, демпферов, сил `cRes`/`kDef` и затенения `occ`.

### Соответствие источникам

- `W = Q·N` — совпадает.
- `Q = k_a·C1/(4πR²)` — совпадает буквально; `C1 = 4πG`.
- `N = Vq = hSq` — в коде `V`, `q`, `h`, `S` явные, `N = V·q`, и масса `m = k_v·N`. Изменение `q` меняет и массу, и заряд.
- `F = f(α)·n_f·W` — совпадает; `n_f = k_v·N_i`.
- Кулон в монографии и в доступных фрагментах фильма не упоминается: заряд — только общий количественный показатель, для тяготения — масса.

### Дискретное и непрерывное

Модель следует разбиению «частицы + поле»: частицы дискретны, поле непрерывно. Каждое тело — однородная сфера: снаружи поле `1/r²`, как у точечного источника, внутри — `∝ r`.

### Только доказанные частицы

В модели только частицы, доказанные напрямую и с измеренной массой: протон (Резерфорд, 1919), нейтрон (Чедвик, 1932), электрон (Томсон, 1897). Каждая — одно однородное тело.

Кварков и «массы связи» нет, хотя они были в промежуточной версии:

- кварки доказаны только косвенно (рассеяние на протонах, SLAC 1968–69), свободными их никогда не наблюдали;
- их массы (токовые 2.16 / 4.67 МэВ, конституентные ~312 МэВ) — вычисленные или модельные параметры, а не измерения;
- «масса связи» вообще не частица.

В коде нуклон — тело с тегами `nuc` и `nk` (`p`/`n`), с ним работают как с группой (`orbit`, удаление, центр масс).

## 2. Атомные единицы

- `m_p = 1836`, `m_n = 1839`, `m_e = 1` — калибровочные значения; в модели масса вычисляется: `m = N = V·q`;
- плотность одна для всех тел: `q = 2.39·10⁵` (калибрована по `N(e⁻) = 1`); радиус — из `N = V·q`: `rad_e = 0.01`, `rad_p ≈ rad_n ≈ 0.1225`; `S = πr²`, `h = 4r/3`, `V = hS`;
- `r0 = 1` — радиус орбиты электрона вокруг p⁺+n⁰; `rn = 0.45` — радиус орбиты нейтрона;
- `G = 2.4·10⁻⁴³` — реальная гравитационная постоянная в атомных единицах;
- частицы рисуются в масштабе объёма: экранный радиус `rad·focal/z`; поле-свечение по умолчанию выключено (клавиша `G`);
- нейтрон входит в атом по умолчанию: каждый атом — дейтерий `p + n + e`, нейтрон на гравитационной орбите `rn = 0.45`; сильного взаимодействия нет;
- старт: один атом `p⁺ + n⁰ + e⁻` (дейтерий) — 3 тела, суммарный импульс 0.
- колесом можно приблизиться до `camR = 0.8`.

Шаг — по динамическому времени (см. §1), до 400 подшагов за кадр.

Справа — панель управления:

- **Режим** — «атомы» (старт с дейтерием) или «песочница» (пустая сцена). Переключение сбрасывает сцену; в песочнице камера ближе (`camR = 2.5`).
- **Частицы** — строки «протон p⁺», «нейтрон n⁰», «электрон e⁻», «атом» с кнопками `−` / `+` и счётчиком; «св N» — сколько из них свободных:
  - `+ p⁺` / `+ e⁻` — свободная частица в покое в случайной точке рядом с центром масс; `−` убирает последнюю свободную (кнопка неактивна, если свободных нет);
  - `+ n⁰` — нейтрон на орбиту `rn·(1+0.35k)` вокруг ядра атома (сначала — атом без нейтрона), `−` убирает последний нейтрон;
  - `+ атом` — дейтерий `p + n + e` рядом с центром масс, `−` удаляет последний атом целиком; атомов может не остаться;
  - в **песочнице** строки «атом» нет; p⁺, n⁰, e⁻ добавляются по одной, все в покое (нейтрон тоже, а не на орбиту).
- **Постоянная G** — ползунок `log10 G` от `−45` до `6` и пресеты «честный» (`2.4·10⁻⁴³`), «демо» (`10⁻⁵`), «1».
- **Симуляция** — пауза, сброс, поле, **камера** (см. ниже), **след** — показать/скрыть следы всех частиц (клавиша `T`, по умолчанию включён). У протона, нейтрона и электрона след цвета своего вида. Он строится по последним 2250 положениям, по одному на шаг интегрирования (было 375, затем 1125). Яркость падает линейно с возрастом точки, `0.10·(1 − возраст/2250)`, то есть след гаснет вдвое медленнее, чем при 1125. След пишется и когда скрыт, поэтому при включении сразу виден целиком. Рисуется полосами по 24 уровням яркости — одна обводка на полосу, а не на каждый отрезок; «? подсказки» — управление камерой и границы модели.

### Камера (замкнутая упругая сфера)

Включается кнопкой «камера» в разделе «Симуляция». Под ней ползунки: радиус покоя `R₀` (0.3–10; по умолчанию 5 в «атомах», 1.5 в песочнице), заряд стенки `N` (10¹–10⁶, по умолчанию 10³) и упругость `κ` (10⁰–10⁶, по умолчанию 10⁴). Центр камеры — центр масс сцены в момент включения или сброса. Новые тела кладутся не дальше `0.8·R` от центра.

Стенка работает **через ту же формулу**:

- стенка — источник с зарядом `N` и `f(α) = −1` (отталкивание). На тело на расстоянии `d = R − r` до стенки действует `W = Q(d)·N`, а `F = f(α)·n_f·W` направлена от стенки. Вплотную к стенке сила очень большая;
- при `d < δ = 0.02` действует тот же внутренний закон, что у тел: `N(d) = N·(d/δ)³`, поэтому сингулярности нет;
- стенка действует **только изнутри** (`d > 0`). Тело, которое пробило её на большой скорости, дальше летит свободно и стенку не толкает;
- энергия тела у стенки `U = −f(α)·kQ·N_i·N·φ(max(d, 0), δ)` — та же `φ`, что для пар тел; снаружи это константа `φ(0)`, непрерывно продолжающая внутреннюю.

**Упругость.** Радиус `R` — отдельная степень свободы:

- инерция `m = k_v·N`;
- пружина к `R₀`: `½K(R−R₀)²`, жёсткость `K = kQ·N·κ`;
- **затухание радиуса** `ζ` (по умолчанию 1 — критическое): растянутая стенка возвращается к `R₀` спокойно, без колебаний и без жёсткого упора. Скорость радиуса гасится как `e^(−2ζω·t)`, где `ω = √(K/m) = √(kQ·κ)`;
- реакция тел (давление) растягивает стенку, пружина возвращает её к `R₀`.

**Вязкий слой у стенки.** В слое толщиной `h = (h/R)·R` (по умолчанию 0.2·R) тело тормозится относительно стенки. Скорость к стенке гасится с темпом `γ = вязкость·ω·(1 − d/h)²` — чем ближе к стенке, тем сильнее. Сила торможения передаётся стенке, импульс пары сохраняется, поэтому тело толкает стенку и растягивает её. Отталкивание `Q(d)·N` остаётся как было.

Вязкость и затухание — **добавка модели, не формулы**. Энергия уходит в «потери» стенки. Они считаются точно (`½μ(u² − u′²)` для тела и `½m(Ṙ² − Ṙ′²)` для радиуса), и сводка показывает их и `ΔE/E` для `E + потери`, так что баланс энергии остаётся проверяемым.

Ползунки камеры: `R₀`, `N`, `κ`, «вязкий слой h / R» (0.02–0.5), «вязкость» (10⁰–10³, по умолчанию 30), «затухание ζ» (0–2). При `ζ = 0` и вязкости, близкой к нулю, камера снова сохраняет энергию.

История:
1. Сначала пружина работала в обе стороны, а стенка толкала тела с обеих сторон. Быстрый протон (`v = 2`) пробивал стенку, давил на неё снаружи, и через 11 с `R` уходил в минус. Рисование падало с ошибкой `createRadialGradient: r0 < 0`.
2. Логарифмическая пружина не давала `R` уйти в минус, но после сильного растяжения стенка сжималась почти до нуля.
3. Жёсткий упор в `R₀` был признан слишком жёстким.

Теперь торможение вязкое, а возврат — с затуханием. Рисование вырожденной сферы дополнительно пропускается, а `R` страхуется снизу на `0.05·R₀`.

Добавки модели, которых нет в формуле (4): знак `f(α) = −1`, отсчёт `d` от ближайшей точки стенки и пружина. Импульс тел с камерой не сохраняется — стенка внешняя, её центр закреплён.

Внизу — **описание частиц**: по карточке на протон, нейтрон и электрон. В карточке:

- название и символ, кем и когда открыта;
- `N`, масса в МэВ (938.2 / 939.7 / 0.511) и радиус из `N = V·q`;
- электрический заряд (только подпись, кулона нет);
- роль в модели;
- «в сцене N» — сколько таких тел сейчас.

Значения берутся из тех же констант, что и в динамике. Частицы, которых нет в сцене, приглушены. Панель сворачивается; на узком экране она свёрнута по умолчанию.

Слева — сводка: состав, `A`, `Z`, число тел, `E`, `ΔE/E` от последнего изменения состава или `G`, время. «формула и N = V·q» раскрывает подробности. На узком экране панель уходит вниз.

Клавиши: `Space` — пауза, `R` — сброс, `G` — поле, `T` — след, `WASD`/`Q`/`E` — камера.

## 3. Проверки

### 1/r²

Два протона, `G = 1`:

| R | a = Q·N | Q·N·R² |
|---|---|---|
| 1 | 1836 | 1836 |
| 2 | 459 | 1836 |
| 4 | 114.75 | 1836 |
| 8 | 28.6875 | 1836 |

`Q·N·R² = G·m_p` — точно.

### Целостность формулы (после всех правок)

Силы из `accelerate()` сравниваются с численным градиентом полной энергии `−∂E/∂x` из `totalEnergy()`. Конфигурация: 3 p⁺, 2 n⁰, 3 e⁻ в случайных местах, есть тела внутри чужих шаров (e⁻ в p⁺, p⁺ в n⁰); с камерой — тело в слое `δ` у стенки и тело снаружи.

| проверка | результат |
|---|---|
| `Q(2) = k_a·C1/(4π·4)` при `G = 1` | 0.25 = G/4 — точно |
| `N = h·S·q`, `m = N` для p⁺ и e⁻ | 1836 и 1, `m === N` |
| p⁺–e⁻ на `R = 3`: `F = G·m₁m₂/R²` | −204.000 = −1836/9; сумма сил 6·10⁻¹⁴ |
| сумма сил по 8 телам (без камеры) | ~10⁻⁹ при силах ~10³ — действие = противодействие |
| `F = −∂E/∂x`, без камеры | расхождение ≤ 3·10⁻⁶ (точность конечной разности) |
| `F = −∂E/∂x`, с камерой | ≤ 3·10⁻⁵ |
| сила на радиус камеры `m·R̈ = −∂E/∂R` | расхождение 5·10⁻¹⁰ |
| после исправления камеры (тело снаружи стенки, `R > R₀`) | тела 1.3·10⁻⁶, радиус 5·10⁻⁸ |

Сила, потенциал и стенка согласованы: всё идёт через одну `QN` и одну `φ`.

### Действие = противодействие, поле внутри шара

- p⁺ и e⁻ на расстоянии 0.05 (электрон внутри протона): `m_p·a_p + m_e·a_e = 0` точно;
- `a_e = G·N_p·r/R³ ≈ 5·10⁴` — конечно, сингулярности нет.

### Сохранение (дейтерий)

| G | время | max ΔE/E | импульс | R(p–n) | R(p–e) |
|---|---|---|---|---|---|
| 1 | 5 с | 9·10⁻⁸ | ~10⁻⁹ | 0.4499…0.4502 | 0.78…1.26 |
| 10⁻⁵ | 20 с | 2·10⁻⁹ | ~10⁻¹³ | 0.4500…0.4501 | 0.77…1.22 |
| 2.4·10⁻⁴³ | 10 с | 0 | ~10⁻³³ | 0.45 | 1.09 |

`R(p–e)` колеблется, потому что электрон обращается вокруг центра масс p+n, а протон сам ходит по кругу радиуса ~0.22.

## 5. Границы модели

- При честном `G` поле невидимо (`a_G ≈ 10⁻⁴⁰`) — это правильный результат, а не баг.
- Кулона нет: электрон удерживается только гравитацией; химии и `H₂` в модели нет.
- Нейтрон держится только гравитацией. При честном `G` орбита невидима, при демо `G` (и сбросе `R`) — видна; сильного взаимодействия нет, это не ядро.
- Внутреннего строения нуклонов нет: протон и нейтрон — однородные шары (кварки убраны как недоказанные напрямую, см. §1).
- Кора нет: тела проходят друг сквозь друга, внутри шара поле линейно спадает к нулю.
- Пары внутри шара считаются как «точка в однородном шаре радиуса `max(rad_i, rad_j)`» — для перекрытия двух сфер это приближение.

## 6. Известные ограничения

- С камерой энергия тел не сохраняется: часть уходит в вязкость слоя и затухание радиуса. Проверяется баланс `E + потери`. Очень быстрые тела (`v ≳ 3` при «демо») могут прорваться сквозь слой; помогает больше вязкости или больше `N`.
- Камера отталкивает по ближайшей точке стенки, поэтому её поле есть во всём объёме (у центра `kQ·N/R²`). При малом `R₀` и большом `N` это заметно влияет на движение внутри. Вплотную к стенке поле очень сильное.
- Поле считается за `O(N²)`.
- Несколько нейтронов могут перекрываться.
- При больших `G` шаг становится мелким; если 400 подшагов за кадр не хватает, время замедляется.
- Новый атом (`+ атом`) запускается с нулевым импульсом относительно мира, но в поле уже существующих атомов — орбиты не строго круговые.
- `window.__h2d` открывает `accelerate`, `step`, `totalEnergy`, `dynTime`, `reset` для проверок из консоли.
